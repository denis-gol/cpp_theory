# коллекция кода
---
Схема работы "клиент-сервер" через сокет AF_LOCAL.
---

## базовая работа сокета AF_LOCAL.
- Общение клиента с сервером, передача команд через struct.  
- Простое логирование (в файл, т.к. демон в cout не пишет)

### Основные файлы:
- Connect/Bind - создание сокета, установление связи итд. Connect - сторона клиента, Bind - сервера.  
- main_client.cpp - подключение к сокету, прослушивание/отправка.
- main_daemon.cpp - подключение клиента (accept), прослушивание/отправка.
- Logger.h - простенький логгер в файл.
